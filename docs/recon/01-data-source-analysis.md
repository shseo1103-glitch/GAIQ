## 5. ML 모델 학습 가능성에 대한 현실적 평가

**실측 row 42건(그중 공정+물성 매칭 완전한 것은 10건 미만)**으로는:

- ❌ **딥러닝(신경망) 모델**: 전혀 부적합. 최소 수백~수천 row가 필요하며, 현재 데이터로는 과적합이 필연적.
- ⚠️ **회귀모델(선형/다항/Ridge)**: 부스바 온도상승 데이터(12개 조건, row20-28)처럼 단일 변수(전류)에 대한 반응 곡선은 회귀로 피팅 가능. 단 일반화(다른 SQ, 다른 재질에 대한 외삽)는 위험.
- ✅ **트리기반 모델(Random Forest, Gradient Boosting)**: 소량 데이터에서도 비교적 안정적이나, 42건은 여전히 부족. 최소 100건 이상 확보 전까지는 "모델"이라기보다 **경험적 lookup table + 전문가 보정** 수준으로 사용하는 것이 현실적.
- ✅ **현재 최선의 접근**: (1) 이미지 재판독(그래프 픽셀값 추출)으로 A그룹 내 숫자 미기재 항목 보강, (2) C그룹 외부논문 데이터를 물리모델(예: ρ∝La⁻¹, K∝La^(1/3))의 파라미터 추정에 활용, (3) 실측 데이터가 쌓일수록 회귀→트리기반으로 순차 고도화하는 **단계적 로드맵**.
- **추가 데이터 확보 우선순위**: (a) 2024-7-30 보고서의 IR카메라/전압-온도 원본 이미지 재판독, (b) 위탁개발 완료보고서의 "별첨" 기술문서 확보, (c) 사업계획서 3종의 출처/시기 정리(중복 프로젝트 여부 확인)
